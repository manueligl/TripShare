# TripShare

Aplicación de escritorio desarrollada en Java para organizar viajes compartidos entre amigos y gestionar los gastos comunes.

## Tecnologías utilizadas

- Java 21
- JavaFX
- MySQL
- JDBC
- Maven

## Arquitectura

El proyecto utiliza el patrón MVC (Modelo-Vista-Controlador).

- Modelo: gestión de los datos y operaciones relacionadas.
- Vista: interfaces gráficas desarrolladas con JavaFX y FXML.
- Controlador: gestión de eventos e interacción entre la vista y el modelo.

## Base de datos

MySQL - `viajes_compartidos`
